# TIL (2026.01.14) — GMS 소개 및 사용법

## GMS란?
**GMS (Generative AI Management System)**  
다양한 생성형 AI API(OpenAI, Gemini, Claude 등)을 **하나의 통합된 키 관리와 크레딧 시스템으로 관리**할 수 있는 플랫폼

---

## 도입 배경
- 여러 종류의 생성형 AI를 사용할 때마다 **API Key를 따로 관리해야 하는 불편함**이 존재
- 각 서비스별 크레딧 충전 방식이 달라 **비용 낭비 및 관리 복잡도 증가**
- 이를 해결하기 위해 **GMS를 통해 중앙 집중형 관리 체계** 구축

---

## GMS 주요 기능 및 사용법

### 접속 및 신청
- 경로: `project.ssafy → ☰ (hamburger menu) → GMS`
- Key 발급 절차:
  1. key 발급 신청
  2. 신청서 작성 (사용 한도 및 계획 입력)
  3. 제출 및 승인 대기

### 인증 방법
- **OpenAI**
  ```bash
  curl "URL"
  -H "Authorization: Bearer $GMS_KEY"
  ```

- **Gemini**
  ```bash
  curl "URL"
  -H "x-goog-api-key: $GMS_KEY"
  ```

- **Claude**
  ```bash
  curl "URL"
  -H "x-api-key: $GMS_KEY"
  ```

### GMS 사용 흐름
1. Key 조회 → 복사
2. 예제 코드에 GMS_KEY, GMS_URL 적용
3. 사용 토큰 수 × 단가만큼 크레딧 자동 차감
