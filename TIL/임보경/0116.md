# TIL (2026.01.16) — Unity Asset 활용 및 glb 변환 시도

## 학습 주제
오늘은 **Unity Asset을 다운로드받아 Unity Hub에서 활용하는 과정**을 실습함.
3D 모델을 Unity 프로젝트에 적용하고, 이를 **glb 파일로 변환하여 웹 환경(VS Code)** 에서 사용하는 방법을 시도함.

---

## 진행 과정

### 1. Asset 다운로드 및 추가
- Unity Asset Store에서 무료 3D 모델 및 패키지 다운로드함.
- Unity Hub를 통해 **새 3D 프로젝트 생성** 후, 다운받은 Asset을 Import함.
- 씬(Scene)에 오브젝트를 배치하고, **조명(Light)과 재질(Material)** 세팅을 테스트함.

### 2. 사용법 익히기
- **Hierarchy / Inspector / Project** 패널의 구조를 익히며, 이를 이용한 오브젝트 관리 방식 이해함.
- Asset의 **Prefab 구조**와 **Export 옵션**을 조사함.
- 웹에서 활용하기 위해 모델을 **glb/gltf 형식**으로 변환할 수 있을지 검토함.

---

## 시도한 변환 과정 (glb Export)
1. Unity 내의 **Export 기능**을 사용해 모델을 내보냄.
2. 변환된 파일을 외부 툴을 이용해 `.glb` 파일로 변환 시도함.
3. **VS Code 환경에서 로드 시 에러 발생**.
   - 텍스처 누락, 메타데이터 변환 실패 등의 이유로 정상적으로 로드되지 않음.
   - 결과적으로 Unity 기본 export만으로는 정상적인 glb 변환이 어려움을 확인함.

---

## 배운 점
- Unity Asset 구조와 에디터의 기본적인 사용법을 익힘.
- Unity에서 생성한 모델을 웹에서 직접 활용하기 위해서는 단순 Export 이상의 변환 과정이 필요하다는 점을 이해함.
- glb는 범용성이 높지만, Unity의 기본 도구만으로는 완전 호환이 어려움을 알게 됨.

---

## 오늘의 회고
- Asset을 직접 다뤄보며 Unity의 에디터 구조와 워크플로우 이해도가 높아짐.
- glb 변환 과정에서 발생한 에러를 통해 **3D 포맷 간의 데이터 손실과 호환성 한계**를 배움.
- 이번 시도는 변환까지 완성하지는 못했지만, 웹용 3D 모델링 연결의 기초를 파악할 수 있었던 유의미한 경험이었음.
