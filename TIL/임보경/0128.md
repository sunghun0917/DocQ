# TIL (2026.01.28) — Git 브랜치 전략 재정비 및 게임 UI/UX 개선

## 오늘의 주제
오늘은 꼬여버린 **Git 커밋 이력을 정리**하고 올바른 브랜치 전략을 재수립한 후, **게임 내 룰렛과 미니게임의 디자인 및 레이아웃을 대폭 개선**하는 작업을 진행함.

---

## 문제 상황

### 1. Git 커밋 이력 꼬임 및 브랜치 관리 부재
- 이전 작업 중 커밋이 꼬이거나 불필요한 변경사항이 포함되어, 깔끔하게 되돌리고 다시 시작해야 할 필요성 발생.
- 팀원들과의 협업 규칙(브랜치 명명, Merge 절차)을 준수하며 안전하게 작업할 환경을 만들어야 함.

### 2. 룰렛 및 미니게임 UI 가독성 문제
- **문제 룰렛**: 디자인이 단순하고 투박하여 증강 룰렛과 이질감이 들며, 텍스트 정렬이 맞지 않음.
- **미니게임(MashGame, SequenceGame)**: 요소 간 간격이 너무 좁아 답답해 보이고, 특히 `SequenceGame`은 모달 크기가 작아 내용물이 겹치거나 잘리는 현상 발생.

---

## 해결 과정

### 1. Git 이력 정리 및 워크플로우 재정비
- **Hard Reset**: `git reset --hard HEAD~2`를 통해 문제가 발생하기 전 시점으로 깔끔하게 되돌림.
- **브랜치 전략 준수**:
    - `develop` 브랜치에서 최신 상태를 당겨온 후(`pull`), 새로운 Feature 브랜치(`feature-front/modify-game-ui`)를 생성하여 작업 시작.
    - 작업 중간중간 `git fetch` & `git merge origin/develop`을 수행하여 팀원들의 최신 코드를 내 브랜치에 안전하게 합치는(Sync) 습관을 들임.

### 2. 룰렛 디자인 리팩토링 (`RouletteOverlay.vue`)
- **디자인 통일**: CSS `conic-gradient`를 활용하여 증강 룰렛과 동일한 색상 패턴으로 변경, 전체적인 게임 톤앤매너를 맞춤.
- **텍스트 정렬 보정**: 회전(`rotate`)과 비틀기(`skew`)가 적용된 룰렛 조각 내에서, 글자가 정확히 중앙에 오도록 `transform-origin`과 `translateX`를 정밀하게 조정함.

### 3. 미니게임 레이아웃 최적화 (`SequenceGame.vue`, `MashGame.vue`)
- **테스트 환경 구축**: 매번 게임을 플레이하며 확인하는 비효율을 막기 위해, `/test` 라우터를 파서 **미니게임 컴포넌트만 독립적으로 확인하는 테스트 페이지**를 만들어 개발 속도를 높임.
- **MashGame 간격 조정**: Flex 컨테이너의 `gap` 속성을 활용하여 요소들 사이의 시원한 간격을 확보.
- **SequenceGame 구조 개선**:
    - 모달 크기 제한 때문에 내용이 겹치는 문제를 해결하기 위해, 게임 컴포넌트에 `min-h`를 주어 실행 시 모달이 자연스럽게 늘어나도록 처리.
    - `items-center`로 인한 Grid 너비 축소 문제를 `w-full`과 `max-w` 설정으로 해결하여, **반응형이면서도 중앙 정렬된 안정적인 레이아웃**을 구현.

---

## 배운 점
- **Git 협업의 정석**: 내 브랜치에만 몰두하는 것이 아니라, 주기적으로 `develop` 내용을 가져와서 충돌을 미리 방지하는 것이 중요하다는 점.
- **CSS Transform & Origin**: 요소를 회전시킬 때 '어디를 축으로 돌릴 것인가(`transform-origin`)'가 정렬의 핵심임을 깨달음.
- **효율적인 디버깅**: 복잡한 게임 로직 안에서 UI를 수정할 때는, 해당 컴포넌트만 떼어내서 볼 수 있는 **Test View**를 만드는 것이 정신 건강과 퇴근 시간에 이롭다.

## 오늘의 회고
- 처음에는 "그냥 간격만 띄우면 되겠지"라고 생각했지만, Flex와 Grid가 얽히면서 의외의 곳에서 모양이 틀어지는 것을 경험했다.
- 하지만 코드를 덕지덕지 붙여서 해결하기보다, 원인(부모 Flex의 영향 등)을 파악하고 정석적인 방법(`w-full`, `gap` 등)으로 해결해서 뿌듯하다.
- 무엇보다 꼬였던 Git을 풀고, 깔끔한 브랜치 전략으로 작업하니 마음이 편안하다.
