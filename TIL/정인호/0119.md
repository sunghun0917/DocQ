# 3D 보드 게임: GLTF 모델 기반 동적 룰렛 시스템 (TIL)

오늘 구현한 **3D 보드 게임용 룰렛 시스템**은 단순 UI를 넘어, 실제 3D 에셋(.glb)과 고성능 애니메이션 엔진을 결합하여 구현되었습니다. 서버의 확정된 결과값을 바탕으로 박진감 넘치는 시각적 연출을 제공하는 것이 핵심입니다.

---

## 🚀 프로젝트 개요
기존의 2D CSS 룰렛에서 한 단계 진화하여, **TresJS(Three.js)**와 **GSAP**를 활용한 3D 룰렛 시스템을 구축했습니다. 서버에서 결정된 이동 칸수를 전달받아 3D 공간 상에서 정교하게 회전하며 멈추는 **결정론적 3D 애니메이션(Deterministic 3D Animation)** 방식을 사용합니다.

---

## 🛠 주요 기술 스택
- **3D Engine**: TresJS (Vue-Three.js Bridge)
- **Asset**: GLTF (.glb) 모델링 파일 (원판 및 화살표)
- **Animation**: GSAP (GreenSock Animation Platform)
- **Framework**: Vue 3 (Composition API)
- **Communication**: WebSocket (Stomp)

---

## 💡 핵심 구현 포인트

### 1. GLTF 모델 로딩 및 3D 렌더링
`GLTFLoader`를 사용하여 실제 3D 모델(`roullet.glb`, `arrow.glb`)을 비동기로 로딩하고 `TresJS` 환경에서 렌더링합니다.
- **Mesh 분리**: 회전하는 **원판(Wheel)** 부위와 고정된 **화살표(Arrow)**를 별도 그룹으로 관리하여 모델링의 각도를 독립적으로 제어합니다.
- **Scale/Position 보정**: 다양한 환경에서 일관된 크기를 보이기 위해 룰렛 모델의 크기와 위치를 `THREE.Box3`를 활용해 동적으로 보정합니다.

### 2. GSAP를 활용한 부드러운 회전 제어
기존 CSS 애니메이션 대신 **GSAP**를 사용하여 더 정밀하고 성능이 뛰어난 회전 곡선을 구현했습니다.
- **Ease 효과**: `power4.out` 이징을 적용하여 실제 물리적인 마찰력이 작용하여 멈추는 듯한 고퀄리티 감속 연출을 실현했습니다.
- **수치 동기화**: GSAP가 보간하는 `rotation` 값을 Vue의 `ref`로 관리하고, 이를 `watch`하여 3D 모델의 각도 속성에 즉시 반영합니다.

```typescript
// GSAP 기반 회전 시퀀스
gsap.to(rotation, {
    value: targetRotationValue,
    duration: 3,           // 3초간 회전
    ease: "power4.out",    // 후반부 부드러운 감속
    onComplete: () => { isSpinning.value = false }
})
```

### 3. 정밀한 영점 및 3D 타겟팅 계산
3D 모델의 실제 각도와 데이터 상의 각도를 일치시키기 위해 수학적 보정을 거칩니다.
- **Section Angle**: `360 / labels.length`를 통해 한 칸당 각도를 계산합니다.
- **Landing Offset**: 3D 모델링 파일 자체의 초기 각도(영점)를 맞추기 위해 보정값(`landingOffset`)을 더해 서버 결과값과 화살표의 위치가 1도 단위까지 정확히 일치하도록 설계했습니다.

### 4. 확장 가능한 3D 테스트 랩 (Lab) 구축
다양한 기기 및 사양에서 룰렛의 가시성을 확보하기 위해 **테스트 랩(RouletteTest.vue)** 화면을 별도로 구현했습니다.
- 실시간으로 카메라 위치(`cameraPosition`), 모델 스케일(`modelScale`), 화살표 오프셋(`arrowOffset`) 등을 조정하며 최적의 **'골든 세팅'** 값을 찾아 실제 게임 화면에 적용했습니다.

## 🎨 디자인 및 UX 상세
- **현장감 있는 렌더링**: `TresAmbientLight`와 `TresDirectionalLight`를 조합하여 3D 모델에 입체감과 그림자를 부여했습니다.
- **상호작용성**: 사용자가 룰렛을 돌리는 순간부터 멈추는 순간까지의 모든 상호작용은 비동기 시퀀스로 제어되어, 결과가 나온 후 300ms~1000ms의 대기 시간을 거쳐 캐릭터 이동으로 부드럽게 이어지도록 설계했습니다.

---

## 🔍 성찰 및 개선 사항
- **구현 방식의 전환**: 초기에는 CSS 기법(clip-path 등)을 고려했으나, 게임의 몰입도를 위해 실제 3D 모델을 사용하는 방향으로 선회했습니다. 이 과정에서 `TresJS`의 성능 이점을 극대화할 수 있었습니다.
- **영점 보정의 중요성**: 3D 모델마다 중심축과 시작 각도가 다르기 때문에, 이를 코드에서 동적으로 오프셋을 줄 수 있는 환경(테스트 랩)을 미리 만든 것이 개발 속도를 크게 높여주었습니다.
