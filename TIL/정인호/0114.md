### 원인 분석

#### 1. 깊이(Z축) 좌표계의 불일치 (가장 결정적인 원인)

**sequence_30x258 (문제 파일)**
- **Pose Z값**: 평균 -0.20 (최소 -0.96 ~ 최대 0.63)
  - 몸통은 화면 안쪽 깊이 있는 공간에서 움직임
- **Hand Z값**: 평균 ~0.00 (최소 -0.03 ~ 최대 0.01)
  - 손은 깊이감이 거의 없이 화면 평면(Z=0)에 붙어 있음
- **결과**: 몸은 뒤(-0.2)에 있는데 손은 앞(0.0)에 떠 있는 형태
  - 손목이 끊어지거나 손이 몸을 따라가지 못하고 둥둥 떠다니는 현상 발생

- **결과**: 손과 몸의 깊이 값 범위가 일치
  - 손이 몸과 같은 3D 공간 안에 존재하므로 자연스럽게 연결된 움직임

#### 2. 좌표 범위(Scale)의 불일치

**sequence_30x258**
- **Pose**: 월드 좌표계(World Landmark) 혹은 넓은 범위 사용
  - Y축이 1.44까지 벗어남
- **Hand**: 화면 정규화 좌표계(Normalized, 0~1) 범위에 제한
- **결과**: 몸이 크게 움직일 때 손은 정해진 작은 박스(화면) 안에서만 움직임
  - 동작이 매칭되지 않음

### 결론

현재 `sequence_30x258` 데이터는 다음과 같은 상태:
- **몸통**: 전역(Global) 좌표계 사용
- **손**: 지역(Local) 좌표계 사용
- 두 좌표계가 단순히 합쳐져 있는 상태

### 원인

MediaPipe의 Hand Landmark는 기본적으로:
- 손목을 원점으로 하거나
- 화면 2D 좌표로 출력됨

따라서 **손의 좌표를 몸통(Pose)의 손목 위치를 기준으로 더해주는 좌표 변환(Global Transformation) 과정이 누락**된 것으로 판단됨

### 해결 방향

데이터를 생성하는 단계에서 다음 처리가 필요:
1. Hand 좌표를 Pose의 손목(Wrist) 좌표 기준으로 변환
2. 전역 좌표계로 통일된 좌표 후처리 적용

```
Hand_Global = Pose_Wrist + Hand_Local
```
