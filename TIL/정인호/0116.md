# 타입스크립트 제네릭

우리가 프로그래밍을 할 때 사용하는 변수는 데이터 값의 유연성을 위해서이다. 변수는 변할 수 있는 것, 상수는 항상 고정된 것.

number, string으로 사용했던 타입은 항상 고정되어 절대 변하지 않는 타입을 사용해왔다.

그리고 여기에 약간의 유연성을 더한 것이,
number | string | undefiened 유니온 타입이다.

즉 type의 변수화를 의미한다.

### 제네릭 
```
<T> -> T라는 임시 타입을 쓰겠다.
x: T, y: T -> 첫 번째 x의 타입이 T라면 두 번째 y의 타입도 T이다.
: T -> 결과값도 입력받은 T가 나온다.

function add<T>(x: T, y: T): T
```

제네릭을 사용함으로써 하나의 함수 로직으로 모든 타입을 커버할 수 있어서 코드가 훨씬 깔끔하고 재사용하기 좋아
