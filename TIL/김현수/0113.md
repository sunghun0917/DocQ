### 주제: WebSocket 개념 이해 및 HTTP와의 차이

### 📌 오늘 학습한 내용

* WebSocket은 클라이언트와 서버 간 **양방향 통신을 지속적으로 유지**할 수 있는 프로토콜이다.
* 기존 HTTP 통신은 요청–응답 구조로, 실시간 상호작용에 한계가 있다.
* WebSocket은 최초에 HTTP Handshake를 거친 후 **단일 연결을 유지**한다.

### 📌 HTTP vs WebSocket 차이

* HTTP는 클라이언트 요청이 있어야 서버가 응답할 수 있다.
* WebSocket은 서버와 클라이언트가 언제든지 메시지를 주고받을 수 있다.
* 실시간 게임, 채팅, 알림 시스템에 WebSocket이 적합하다.

### 📌 WebSocket 동작 흐름

1. 클라이언트가 HTTP 요청으로 WebSocket 연결을 요청한다.
2. 서버가 이를 승인하면 프로토콜이 WebSocket으로 전환된다.
3. 연결이 유지된 상태에서 양방향 통신이 가능해진다.
