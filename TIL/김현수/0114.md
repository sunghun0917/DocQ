## 📘 TIL – 1월 14일

### 주제: WebSocket 서버·클라이언트 기본 구현

### 📌 오늘 학습한 내용

* WebSocket 서버와 클라이언트의 기본 구조를 직접 구현했다.
* 연결, 메시지 송수신, 연결 종료의 흐름을 실습으로 이해했다.

### 📌 서버 측 핵심 요소

* WebSocket 엔드포인트 설정
* 클라이언트 연결(Session) 관리
* 메시지 수신 및 브로드캐스트 처리

### 📌 클라이언트 측 핵심 요소

* WebSocket 객체 생성
* 서버 연결 이벤트(onopen) 처리
* 메시지 수신 이벤트(onmessage) 처리

### 📌 메시지 흐름

1. 클라이언트가 WebSocket 서버에 연결한다.
2. 메시지를 서버로 전송한다.
3. 서버는 메시지를 수신하여 다른 클라이언트에게 전달한다.

### 💭 느낀 점

* WebSocket은 구현 자체는 단순하지만, **연결 상태 관리가 핵심**이라는 점을 느꼈다.
* 여러 사용자가 동시에 접속하는 환경을 고려해야 함을 인지했다.
