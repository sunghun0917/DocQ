### 1️⃣ Concurrent Map의 정의

`ConcurrentMap`은 **멀티스레드 환경에서 안전하게 동시 접근이 가능한 Map 자료구조**이다.
일반적인 `HashMap`은 여러 스레드가 동시에 접근할 경우 데이터 불일치나 예외가 발생할 수 있지만,
`ConcurrentHashMap`은 내부적으로 동기화 메커니즘을 적용하여 이러한 문제를 방지한다.

* 전체 Map에 락을 거는 방식이 아닌 **부분 락(Segment / Bucket 단위)** 구조
* 높은 동시성 환경에서도 성능 저하를 최소화
* 웹 서버, 멀티스레드 기반 애플리케이션에서 자주 사용됨

### 2️⃣ WebSocket의 Subscribe / Publish 개념

WebSocket은 **클라이언트와 서버 간의 실시간 양방향 통신**을 가능하게 하는 프로토콜이다.
특히 Pub/Sub 구조를 활용하면 다수의 사용자에게 효율적으로 메시지를 전달할 수 있다.

#### 🔹 Subscribe

* 클라이언트가 특정 **채널(Topic)** 에 구독 요청을 보내는 과정
* 서버는 해당 채널에 대한 연결 정보를 유지
* 이후 해당 채널에 메시지가 발행되면 자동으로 수신

#### 🔹 Publish

* 서버 또는 클라이언트가 특정 채널로 메시지를 발행하는 과정
* 해당 채널을 구독 중인 모든 클라이언트에게 메시지가 전송됨

📌 이 구조를 통해

* 채팅 서비스
* 실시간 알림
* 게임, 협업 툴
  등을 효율적으로 구현할 수 있다.

---

### ✍️ 오늘의 정리

* ConcurrentMap은 **동시성 문제를 해결하기 위한 핵심 자료구조**
* WebSocket의 Pub/Sub 구조는 **실시간 서비스 구현의 핵심 패턴**
