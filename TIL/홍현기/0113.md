# 오늘의 TIL
### 미팅 회고: 문제의식이 프로젝트의 전부다
📌 오늘 회의의 핵심 주제

기능보다 중요한 것은 ‘문제 정의’와 ‘설득 가능한 흐름’이다.
문제의식이 공감되지 않으면, 어떤 기능을 만들어도 와닿지 않는다.

🎯 프로젝트 평가 기준: “이게 왜 필요한가?”

모든 프로젝트에 공통적으로 제기된 질문:

이 서비스가 정말로 해결하려는 문제가 무엇인가?

이 문제가 사용자에게 실제로 얼마나 아픈 문제인가?

발표를 보는 사람도 공감할 수 있는 문제인가?

기능이 많다고 좋은 프로젝트가 아니라,
하나의 문제를 얼마나 깊게 파고들었는지가 더 중요하다는 결론에 도달했다.

🟢 프로젝트 1: SING쌓임
✅ 출발점은 좋다

농인들이 텍스트 기반 콘텐츠를 이해하기 어려움

자막이 있어도 실제 콘텐츠 소비에는 한계가 있음

❗ 문제점

문제 원인에 비해 기능이 중구난방

기능이 왜 필요한지 논리 흐름이 약함

💡 필요한 흐름 예시

수어는 제2외국어처럼 느껴짐

대부분의 콘텐츠는 텍스트/음성 중심

농인은 현실의 콘텐츠를 온전히 즐기기 어려움

그래서 모든 콘텐츠를 수어로 제공하는 플랫폼이 필요함

이를 위해 제공하는 핵심 기능은 ○○○

👉 이렇게 문제 → 해결 → 기능으로 이어지는 구조가 필요

🤔 비장애인은 왜 이 서비스를 써야 하는가?

여기서 중요한 전략적 선택이 필요하다고 느꼈다.

농인을 위한 전용 콘텐츠 플랫폼으로 갈 것인가?

아니면 농인–비농인 소통 플랫폼으로 갈 것인가?

현재 기획은 두 방향이 섞여 있음 → 메시지가 흐려짐

👉 도메인을 하나로 명확히 정해야 설득력이 생김

❓ 수어 모의면접 기능에 대한 의문

메인 문제의식과 직접 연결되는 기능인가?

아니면 기능 확장을 위한 아이디어인가?

주제를 확장하는 것은 좋아 보이지만,
대회/수상 관점에서는 오히려 집중도가 떨어질 수 있음

🟡 프로젝트 2: LearnFlow
🤔 수상 관점에서의 우려

실제로 써봐야 가치를 느낄 수 있는 서비스

발표 화면만으로는 좋은지 나쁜지 판단하기 어려움

❗ 문제점

관객이 즉각적으로 공감할 만한 문제의식이 약함

“그래서 이게 왜 꼭 필요한가?”가 명확하지 않음

👉 발표 환경에서는 즉시 이해되는 문제 구조가 중요

🔵 프로젝트 3: 시맵스
❓ 문제의식이 불분명

무엇을 해결하려는 서비스인지 명확하지 않음

AI로 기사 추출 → 그게 왜 중요한가?

근본 질문

사람들이 지역/사회 문제에 무관심했던 진짜 이유는?

정보 부족인가, 관심 부족인가, 접근성 문제인가?

👉 기술보다 먼저 사회적 원인 분석이 필요

📌 공통 결론: 문제의식부터 다시 설계해야 한다
✔ 좋은 프로젝트 흐름

사람들이 실제로 겪는 문제 제시

왜 지금까지 해결되지 않았는지 설명

기존 해결 방식의 한계

그래서 우리가 제안하는 새로운 해결 방법

그 해결을 위한 핵심 기능

🎯 사람을 설득하는 서비스 기획이란?
핵심은 이것

문제 정의가 공감되면, 해결책은 자연스럽게 설득된다.
하지만 문제 정의가 약하면, 아무리 기술이 좋아도 와닿지 않는다.

🎭 진지함 vs 위트, 언제 필요한가?

회의 중 나온 중요한 인사이트:

위트는 문제 자체가 가벼울 때만 효과적

사회적, 구조적 문제라면 오히려 진지한 접근이 더 설득력 있음

👉 톤앤매너도 문제의 성격에서 출발해야 한다

✍️ 오늘 회의에서 얻은 교훈

기능은 나중 문제, 문제 정의가 먼저

주제는 넓히기보다 좁고 깊게

발표에서 중요한 건 청중의 즉각적인 공감

기술은 해결 수단일 뿐, 프로젝트의 주인공은 문제

✅ 앞으로의 액션 아이템

각 팀 프로젝트별 문제의식 재정의

핵심 사용자 명확히 설정

기능 목록보다 문제 해결 흐름부터 설계
