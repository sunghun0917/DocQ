# 오늘의 TIL
### ✅ Nginx란?
Nginx(엔진엑스) 는 고성능 웹 서버이자 리버스 프록시(Reverse Proxy),
로드 밸런서, 정적 파일 서버 역할까지 수행할 수 있는 경량 웹 서버 소프트웨어이다.

### ✅ Nginx의 주요 역할

1. 웹 서버 (Web Server)

HTML, CSS, JS, 이미지 같은 정적 파일 제공

빠른 파일 서빙에 최적화

2. 리버스 프록시 (Reverse Proxy)

클라이언트 요청을 받아 내부 서버로 전달

실제 서버 IP를 숨겨 보안 강화

트래픽 분산, 인증 처리 가능

3. 로드 밸런서 (Load Balancer)

여러 서버로 요청 분산

Round Robin, Least Connections 등 방식 지원

4. SSL/TLS 종료 지점

HTTPS 처리 담당

내부 서버는 HTTP만 사용 가능 → 성능 & 관리 편의성 ↑

### ✅ Nginx 장점

매우 빠른 정적 파일 처리

대규모 트래픽 처리 가능

설정이 단순하고 가벼움

프록시, 로드밸런서, 캐시까지 가능

### ✅ Nginx 단점

동적 처리 불가 (WAS 필요)

Apache보다 모듈 확장성은 제한적

설정 실수 시 디버깅이 까다로울 수 있음

### ✅ 언제 Apache를 쓰고, 언제 Nginx를 쓰나?
### Apache가 적합한 경우

PHP 같은 서버 사이드 스크립트를 직접 처리

레거시 시스템 유지보수

### Nginx가 적합한 경우

프록시 서버

MSA 구조

클라우드 배포

트래픽 많은 서비스

요즘 신규 서비스는 거의 Nginx가 기본 선택 !
